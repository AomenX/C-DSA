# C DSA — Data Structures & Algorithms

> Learning Data Structures & Algorithms from first principles, implemented from scratch in C.

This repository documents my journey through **Data Structures & Algorithms**, following the [NeetCode Roadmap](https://neetcode.io/roadmap) while implementing the underlying concepts and data structures myself in **C**.

The goal is not simply to solve problems.

The goal is to understand **why the algorithms work, how the data structures work internally, and how to implement them from scratch.**

---

## 🎯 Goals

- Build a strong foundation in DSA
- Understand the underlying concepts before solving problems
- Implement data structures from scratch in C
- Improve algorithmic thinking and problem-solving
- Analyze **time and space complexity**
- Learn to recognize common algorithmic patterns
- Keep a clean, organized record of my progress
